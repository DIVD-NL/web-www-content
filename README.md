# DIVD Website Content

This repository contains the content for the DIVD website. DIVD (Dutch Institute for Vulnerability Disclosure) is a non-profit organization dedicated to making the digital world safer through responsible disclosure.

## Repository Structure

This repository manages the content of the DIVD website. More details about the structure and how to contribute will be added as the project develops.

## Contributing

If you'd like to contribute to the website content, please feel free to submit a pull request.
